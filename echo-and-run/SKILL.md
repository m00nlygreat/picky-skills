# Echo and Run

1. 요청과 앞선 대화를 바탕으로 사용자가 원하는 결과와 작업 범위를 파악한다. 결과에 영향을 주는 제약과 가정만 추린다.
2. 작업을 시작하기 전에 진행 메시지로 해석을 한 번 전달한다. 사용자가 자기 의도와 맞는지 판단할 수 있도록 무엇을 어떻게 처리할지 자기 말로 짧게 설명한다.
3. 브리핑한 범위에서 같은 턴에 작업을 실행한다. 사용자가 먼저 확인받기를 요청했거나, 결과를 바꾸는 불확실성을 맥락으로 해소할 수 없다면 필요한 답을 받은 뒤 실행한다. 실행 중 사용자가 해석을 바로잡으면 그에 맞춰 남은 작업을 조정한다.
