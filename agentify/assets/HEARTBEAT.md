# HEARTBEAT

프로젝트 작업을 시작할 때 아래 항목의 실행 조건을 확인한다. 명시적인 점검 요청은 요청 범위에 맞춰 즉시 수행한다.

## 활성 점검

- **작업 차단 요인과 문서 연결**. 작업을 시작할 때 알려진 차단 요인과 에이전트 문서 링크를 확인한다. 현재 작업이 막혔거나 유효한 링크를 찾을 수 없으면 영향을 알리고, 범위 안에서 복구할 수 있는 연결은 고친다.

새 항목에는 확인 대상, 작업 시작 같은 실행 조건 또는 반복 주기, 필요한 조치와 보고 기준을 적는다. 반복 주기를 정한 항목에는 마지막 성공 시각을 시간대와 함께 기록한다. 첫 점검은 마지막 성공 기록이 없을 때 수행하고, 다음부터는 마지막 성공 이후 주기가 경과했을 때 수행한다.

실행할 항목이 없으면 종료한다. 세션 점검에서는 조치할 사항이 있을 때만 알리고, 직접 요청받은 점검은 조치 필요 여부나 확인하지 못한 이유를 짧게 답한다.

## 예약

하네스에서 사용자가 요청하거나 동의한 예약을 등록한 경우, 확인된 예약 ID, 주기와 시간대를 기록한다.
