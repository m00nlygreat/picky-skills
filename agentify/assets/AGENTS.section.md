## 에이전트 운영

- 작업을 시작할 때 [SOUL.md](SOUL.md)를 읽고 에이전트의 역할, 태도, 판단 원칙에 적용한다. 지속적인 정체성이나 행동 원칙의 변경은 사용자가 정하거나 확인한 내용을 반영한다.
- 작업을 시작할 때 [MEMORY.md](MEMORY.md)를 읽고 핵심 사실과 사용자 선호를 참고한다. 이 지침과 현재 사용자 요청을 기준으로 기억을 해석한다.
- 과거 맥락이 필요하면 [기억 인덱스](memory/INDEX.md)에서 관련 기록을 찾아 읽는다. 연관된 결정과 근거는 문서 사이의 상대 링크로 연결한다.
- 프로젝트 작업을 시작할 때 [HEARTBEAT.md](HEARTBEAT.md)를 읽고 현재 작업의 차단 요인, 에이전트 문서 링크, 기한이 된 점검 항목을 확인한다. 사용자가 직접 요청한 경우에는 요청 범위를 즉시 점검한다. 설정된 조치·보고 기준을 적용하고 주기 점검의 성공 시각을 기록한다. 일반 작업에서는 조치가 필요한 결과만 알리고, 직접 점검을 요청받으면 결과를 짧게 답한다.
- 작업을 마칠 때 확인된 장기 선호와 재사용할 사실·결정을 기록한다. 직접 기억·정정을 요청받으면 그 시점에 반영한다. 매 작업에 필요한 정보는 핵심 기억에 두고, 의미 있는 대화·활동은 `memory/YYYY-MM-DD.md`, 프로젝트별 맥락과 재사용할 지식·관찰은 `memory/`의 관련 문서에 기록한다. 근거와 날짜가 판단에 필요하면 함께 남긴다.
- 관련 기억을 먼저 확인해 기존 항목에 정정을 반영한다. 상세 기억을 추가하거나 이동할 때 인덱스와 관련 상대 링크도 갱신한다. 공유 작업공간에는 협업에 필요한 정보만 기록하며 비밀 정보와 대화 원문은 저장 대상에서 제외한다.
- 작업에 적합한 설치 스킬을 사용한다. `agentify`는 사용자가 이 스킬의 사용을 명시적으로 요청한 경우에만 실행한다.
- 작업공간에 접근할 수 있는 하네스 스케줄러는 사용자가 예약을 요청하거나 동의한 경우에 사용한다.
