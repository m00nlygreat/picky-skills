# Agentify

## 실행 조건

사용자가 `$agentify`를 직접 호출하거나 이 스킬을 사용하라고 명시적으로 요청한 경우에만 실행한다. 설치 후 기억 갱신, 사용자 선호 기록, 점검과 예약은 작업공간의 `AGENTS.md`와 `HEARTBEAT.md`에 따라 처리한다.

## 초기화와 연결

사용자가 지정한 작업공간을 사용한다. 경로를 지정하지 않았다면 현재 프로젝트 루트를 사용하고, Git 저장소 밖에서는 현재 작업 디렉터리를 사용한다. 초기화 또는 연결 복구를 요청받으면 이 스킬 디렉터리 기준으로 다음 도우미를 실행한다.

```text
python <스킬 디렉터리>/scripts/init_agentify.py --project-root <작업공간>
```

도우미가 출력한 실제 지침 파일을 읽고 생성된 문서 링크를 확인한다. 기존 문서는 현재 내용을 기준으로 사용한다. 기존 기억을 처음 연결할 때는 실제 문서를 확인해 필요한 항목을 `memory/INDEX.md`에 추가한다. 지침과 충돌하는 기존 설정이 발견되면 그 차이를 알려 해소한다.

### 선택 모듈

사용자가 `USER.md`를 선택하면 새 작업공간과 기존 작업공간 모두에서 초기화 명령에 `--with-user`를 붙인다.

```text
python <스킬 디렉터리>/scripts/init_agentify.py --project-root <작업공간> --with-user
```

도우미는 [USER.md 템플릿](assets/USER.md)으로 빠진 프로필을 만들고, 작업을 시작할 때 읽도록 지침 파일에 연결한다. 프로필에는 사용자가 알려 주거나 확인한 사용자 자신에 관한 사실과 관심사, 취향, 협업 선호 중 계속 참고할 내용을 기록한다. 기존 프로필은 그대로 연결한다. 지침 파일에 `USER.md` 링크가 있으면 이후 기본 초기화에서도 빠진 프로필을 복구한다.

## 명시적으로 요청한 예약 등록

사용자가 `agentify`로 예약을 등록해 달라고 명시적으로 요청하면 작업공간에 접근 가능한 하네스 내장 스케줄러와 점검 대상, 주기, 시간대를 확인한다. 사용자가 요청 또는 동의한 범위에서 등록하거나 수정한다. 스케줄러를 쓸 수 없으면 세션 점검을 적용한다.

등록 전에 저장된 예약 ID나 작업공간 경로로 기존 예약을 확인한다. 결과가 불확실하면 재시도 전에 예약을 다시 조회한다. 등록이 확인되면 식별자와 실행 주기를 `HEARTBEAT.md`에 기록한다. 예약의 실행 지침에는 대상 작업공간을 지정하고, 실행마다 현재 `AGENTS.md`와 `HEARTBEAT.md`를 읽어 기한이 된 점검을 수행하도록 적는다.
